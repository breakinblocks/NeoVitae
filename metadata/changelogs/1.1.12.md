# 1.1.12

## Changes

- New artwork from Jamiscus. The Ritual Stone and all six elemental variants have been redrawn, each element now carrying its own mark so you can read a ritual layout at a glance.
- The six path blocks, the Hellforged Block and the dungeon Spikes have been redrawn to match.
- Essentia Vitae no longer fills slabs, stairs, fences and other waterloggable blocks by default. The feature is still experimental and can cause some performance issues with some mods, so it now has to be turned on with `essentiaLogging = true` in `config/neovitae-startup.toml`.

## Fixes

- The Teleposition Focus is now made on a tier 3 Ara Vitae, so it no longer turns into the Enhanced Focus the moment it finishes.
- The Sigil of the Green Grove respects FTB Chunks claims. It will not grow anything in a chunk you are not allowed to build in.
- Pin Cushion can be trained again. Being shot by skeletons, blazes or anything else that throws something at you gave the upgrade no progress at all.
