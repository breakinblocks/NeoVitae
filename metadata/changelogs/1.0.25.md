# 1.0.25

## Additions

- Spiritus Gems can now pocket spawners. Sneak and right-click a Monster Spawner or Trial Spawner with a gem holding at least 200 Spiritus; that Spiritus is spent and the spawner drops as an item, keeping its mob and settings so you can set it back down elsewhere. The cost can be adjusted in the server config.

## Changes

- Spiritus essence no longer turns up as random loot in dungeon chests or as a drop from the dungeon's demons. Gather it the intended way, with a Throwing Dagger or a Sentient weapon.
