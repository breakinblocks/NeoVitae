# 1.0.9

## Minecraft 26.1.2 Port (development snapshot)

NeoVitae now runs on Minecraft 26.1.2 (NeoForge 26.1, Java 25), carrying the full 1.0.5–1.0.9 feature set over from the 1.21.1 build. This is a development snapshot still in testing; the 26.1 release is not yet final.

## Fixes

- Ritual Stones now drop when mined.
- Spiritus crystal clusters (Raw, Ruina, Nihilum, Vindicta, Invictus) now drop a single first-stage crystal when mined, regardless of how grown they were.
- Spike Traps now trigger the instant they are placed on an already-powered block instead of waiting for the next block update.
- Blood and Demon Lanterns mine at the correct speed and keep their binding when broken.
- The Slime of Vitae is now fully red, including its outer shell.
