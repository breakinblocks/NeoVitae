# 1.0.9

## Routing Network

- Filter slots now support a per-slot **keep amount**. Scroll over a slot to set it (hold Shift or Ctrl for larger steps); 0 means unlimited. An output face fills its destination up to that many, counting what is already there; an input face leaves that many behind and pulls only the surplus. Works for both items and fluids.
- The filter grid is now nine slots wide, and a new **page** opens automatically as you fill the last one, so a single face can hold as many item or fluid filters as you need. Use the **<** and **>** arrows to page through them.
- You can now drag items and fluids straight from JEI onto a filter slot to set a ghost.

## Ara Vitae

- The altar now holds and transmutes a single item at a time. Hoppers and routing nodes can no longer overfill the basin or set off a runaway whole-stack craft, making the altar far simpler to automate.

## Fixes

- Ritual Stones now drop when mined.
- Spiritus crystal clusters (Raw, Ruina, Nihilum, Vindicta, Invictus) now drop a single first-stage crystal when mined, regardless of how grown they were.
- Spike Traps now trigger the instant they are placed on an already-powered block instead of waiting for the next block update.
- Blood and Demon Lanterns mine at the correct speed, and the Demon Lantern keeps its binding when broken.
