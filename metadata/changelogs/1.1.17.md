# 1.1.17

## Changes

- The Dungeon Alternator can now be crafted in the Hellfire Forge: iron, smooth stone, redstone, and a Tabula Rasa, with 16 Spiritus.
- The Dungeon Alternator is now a configurable redstone timer. Right-click it to set the pulse delay in ticks; a delay of 1 gives a constant signal, and a freshly placed one stays off until configured.
- The Alternator can pause while it receives a hard redstone signal, resuming when the signal is removed. This is on by default and can be toggled in its screen.
- Sneak + right-click an Alternator with a Node Router, then other blocks, to link up to 8 blocks within 256 blocks. Linked blocks pulse along with the Alternator, as if redstone were applied right at them. Sneak + right-click a linked block to unlink it, or the air to forget the selection.
- Holding a Node Router and looking at an Alternator shows lines and outlines to everything linked to it, visible through walls.
- Ethereal Mimic blocks can now be crafted in the Hellfire Forge: smooth stone, a Tabula Animata, a phantom membrane, and a gold ingot make 16, with 32 Spiritus.

- The Teleposer now activates from any redstone signal, not just strong power. A redstone block beside it or weak power through a solid block will set it off.

- Hovering over the Training Bracelet now shows the training plan on your equipped Living Armor: each upgrade and its target level, blocked upgrades in red, and whether other upgrades may train.

## Fixes

- Splash and Lingering Alchemy Flasks now show their Tabula Vitae recipe in JEI and EMI. Looking up either flask used to turn up nothing, because the recipe was only listed under a flask that already had an effect on it.
- The Scriptura Vitae's Alchemist's Craft entry now shows the Splash and Lingering flask recipes on their own page instead of only naming them.
- Routing node faces no longer show as disabled again after closing and reopening the screen. The face was actually still enabled, so clicking the button again turned it off for real; the display now matches what the node is doing.
- Setting an upgrade to level 0 with the Training Bracelet now actually blocks that upgrade from training. It used to remove the cap instead, and in deny mode it let exactly those upgrades keep training. If you set a cap to 0 before this fix, open the trainer and save it again.
