# Translations

Neo Vitae accepts translations as pull requests on GitHub. There is no external
translation platform.

## Where the files are

| Path | Purpose |
| --- | --- |
| `src/generated/resources/assets/neovitae/lang/en_us.json` | Source strings (English). Generated by `./gradlew runData`, never edited by hand. |
| `src/main/resources/assets/neovitae/lang/<locale>.json` | One file per language, for example `de_de.json` or `zh_cn.json`. |
| `translations/glossary.csv` | Terms that must not be translated, and terms that must stay consistent. |

The file name is Minecraft's locale code: lowercase, underscore, no dashes
(`pt_br`, not `pt-BR`). A file with the wrong name loads as nothing, with no
error.

## How to contribute

1. Fork the repository and branch from `main`.
2. Copy `en_us.json` from the generated directory to
   `src/main/resources/assets/neovitae/lang/<locale>.json`, or open the existing
   file for your language.
3. Translate the values. Keys stay exactly as they are.
4. Remove any key you did not translate. Minecraft falls back to English for
   missing keys, so an untranslated key that is left in the file just hides
   future English updates.
5. Check the glossary before translating a proper noun.
6. Open a pull request against `main`. Say which language and roughly how much
   is covered.

Translations only need to be submitted against `main`. The maintainers
regenerate the `dev` branch's language files from `main` with
`tools/port-lang.py`, so the same file ships for both Minecraft versions.

## Formatting rules

These break the game if changed:

- `%%` must stay `%%`. The book renderer runs strings through a formatter, so a
  literal percent sign is escaped. Writing `%` produces a crash or garbled text.
- `%s` and `%d` are substituted at runtime. Keep them, and keep their order
  unless the target language requires reordering (use `%1$s` style if so).
- `[#](8B0000)text[#]()` is book color markup. Translate `text`, never the
  `[#](...)` wrappers or the hex code.
- `\n` line breaks should be preserved.

Source strings cover both supported Minecraft versions, so some strings
describe features not present in every build.
