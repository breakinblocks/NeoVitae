# 1.0.12

## Additions

- The Athanor can now disenchant items. With a Sanguine Reverter in the tool slot, load books and an enchanted item (or an enchanted book); each enchantment is peeled off onto a book, and the cleaned item drops to the output once it is bare. Costs 5 raw spiritus and 100 mB of Essentia Vitae per enchantment moved.

## Changes

- JEI now shows the Blood Tank's upgrade recipe for each tier instead of a text info page, so you can see exactly which tanks and materials make the next tier.
- Tidied the Orb of Vitae pages in the guide book; the redundant crafting-cost pages were removed, since the Orb Tiers page already lists every orb and its Anima capacity.
