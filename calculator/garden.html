Tranquility by type

Each type is added up, then the square roots are summed. Spreading blocks across all seven types gives far more than stacking one.

Bonus steps

Between steps the bonus rises smoothly with tranquility, up to the cap set by your path rings.

Assumes a flat garden with every ring at the same height. In game each ring may sit up to 5 blocks above or below the previous one.
