# 1.0.9

## Minecraft 26.1.2 Port (development snapshot)

NeoVitae now runs on Minecraft 26.1.2 (NeoForge 26.1, Java 25), carrying the full 1.0.5–1.0.9 feature set over from the 1.21.1 build. This is a development snapshot still in testing; the 26.1 release is not yet final.

## Routing Network

- Filter slots now support a per-slot **keep amount**. Scroll over a slot to set it (hold Shift or Ctrl for larger steps); 0 means unlimited. An output face fills its destination up to that many, counting what is already there; an input face leaves that many behind and pulls only the surplus. Works for both items and fluids.
- The filter grid is now nine slots wide, and a new **page** opens automatically as you fill the last one, so a single face can hold as many item or fluid filters as you need. Use the **<** and **>** arrows to page through them.
- You can now drag items and fluids straight from JEI onto a filter slot to set a ghost.

## Ara Vitae

- The altar now holds and transmutes a single item at a time. Hoppers and routing nodes can no longer overfill the basin or set off a runaway whole-stack craft, making the altar far simpler to automate.

## Alchemy Arrays

- The EV cost of the costed arrays (Furnace, Rain, Vortex, Array of Loyal Friends) now lives in the array's data-driven recipe as an `ev_cost` field, so pack makers can retune or zero any of them with a datapack. Free arrays like the Collection Array carry no cost.

## Vitae Link

- New **Vitae Link** block: bind it near an Ara Vitae and it crafts on the altar's behalf, capped at a tier you set (sneak-use to change). It draws EV and rune bonuses from the altar and holds no tank of its own. Crafted from an Ara Vitae in a tier-one+ altar for 1,500 EV.
- Separate input and output slots pipe a reagent in and the product out with no filter tricks; it crafts one item at a time and stops at your tier. Place several around one altar to craft different tiers in parallel.

## Fixes

- The Awakened Activation Crystal now upgrades from a **bound** Weak Activation Crystal and keeps the binding.
- Ritual Stones now drop when mined.
- Spiritus crystal clusters (Raw, Ruina, Nihilum, Vindicta, Invictus) now drop a single first-stage crystal when mined, regardless of how grown they were.
- Spike Traps now trigger the instant they are placed on an already-powered block instead of waiting for the next block update.
- Blood and Demon Lanterns mine at the correct speed and keep their binding when broken.
- The Slime of Vitae is now fully red, including its outer shell.
