# 1.0.14

## Additions

- Ritual stones can now be found in the JEI search by typing "rune" (or "ritual rune", or their element name like "air rune"), alongside the altar runes.

## Changes

- The Output Routing Node is no longer crafted on its own. Craft an Input Routing Node, then flip it between Input and Output forms with a shapeless crafting recipe (put either one in a crafting grid to convert it to the other).

## Fixes

- The Divination and Seer Sigils now report the correct Ara Vitae tier. They were reading one tier too high (a Tier 4 altar showed as Tier 5), and now match the tier numbers used in the guide book.
- Dungeon demon spiritus drops can no longer be multiplied into huge piles by loot-multiplying weapon affixes (such as Apotheosis's Loot Pinata). The demons still drop their themed spiritus on a player kill at the same chances; the drop simply no longer goes through the loot table those affixes amplify.
- Master Ritual Stones respond to redstone again. A redstone signal now pauses a normal Master Ritual Stone (the ritual resumes when the signal is removed), while an Inverted Master Ritual Stone runs only while powered. Neither was reacting to redstone at all.
- Demonite Ore can be mined inside dungeons again. It had become protected like the dungeon's structural blocks, so it couldn't be broken in dungeon rooms; mining it now drops Raw Demonite as intended.
