# 1.1.19

## Fixes

- Activating the Lex Vitae no longer fires its beam straight away. If your beam key is the same button you toggle with, you now have to let go and press again before it fires.
- Polished Bloodstone no longer counts as a Tier 3 Ara Vitae corner. That tier needs Bloodstone Bricks, so it still takes a trip to the Demon Realm.
