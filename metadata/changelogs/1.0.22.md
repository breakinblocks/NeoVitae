# 1.0.22

## Changes

- The Lex Vitae's beam now fires from a rebindable key instead of holding right-click, so right-click is free for your off-hand. You can now raise the Orb of Vitae's shield in your off-hand while wielding an active Lex Vitae. The key is unbound by default; assign it under Controls > Neo Vitae > "Lex Vitae: Fire Beam". Toggling the Lex on and off is still sneak + right-click.
- The Orb of Vitae's shield is now on a rebindable key (Controls > Neo Vitae > "Blood Shield"), bound to right-click by default so it works as before. Because it no longer relies on the right-click item action, it can be held at the same time as the Lex Vitae beam, and you can rebind it off right-click if you prefer. Raising it still needs an Orb of Vitae in your off-hand.
