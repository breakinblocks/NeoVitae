# 1.0.10

## Minecraft 26.1.2

A compatibility build for the current 26.1.2 toolchain. NeoVitae now targets NeoForge 26.1.2.73 and Modonomicon 1.147.0, carrying the full feature set forward.

## Fixes

- Fixed a hard crash on startup in packs running the current Modonomicon (1.147+). NeoVitae's guide book was built against an older Modonomicon API that has since been removed; the mod now uses the new page, predicate, and multiblock registration system, so the game loads normally again.

## Scriptura Vitae (Guide Book)

- Rebuilt the book's styling on Modonomicon's new theme system. The custom page spread, frame, and recipe pages keep their NeoVitae look, and crafting slots and arrows on the Ara Vitae, Hellfire Forge, Tabula Vitae, Alchemy Array, Athanor, Flask, and downgrade pages render correctly again.
