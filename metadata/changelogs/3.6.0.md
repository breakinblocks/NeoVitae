# Neo Vitae 3.6.0

## Routing Node System

### Fluid & Energy Routing

- Routing nodes now transfer fluids and Forge Energy in addition to items
- Input/Output nodes automatically detect adjacent fluid tanks and energy storage
- Any routing filter in a side's slot enables all three resource types on that side
- Empty output tanks are handled correctly (fluid can route to initially empty tanks)

### Routing Channel Abstraction

- Refactored the master node's tick loop into a generic channel-based system
- New `RoutingChannel` API allows addon mods to register custom resource types
- Built-in channels: Item, Fluid, Energy
- `RoutingChannelRegistry.register()` available during mod construction
- All routing interfaces moved to `com.breakinblocks.neovitae.api.routing` for addon access

### Datamap Updates

- Added `base_energy_transfer` (default 10,000 FE) and `energy_transfer_per_upgrade` to routing node stats
- Stack upgrades now boost item, fluid, and energy transfer rates simultaneously

## Bug Fixes

### Ritual System

- Fixed ritual activation showing "no ritual found" when the real error was insufficient LP or wrong crystal level
- Fixed ritual diviner showing false "unable to replace block" warnings (client-side placement check)

### Dungeon Dimension

- Fixed dungeon rooms not generating (all structure NBT files still referenced old namespace)
- Fixed dungeon walls missing due to structure placement in unloaded chunks (now force-loads chunks during generation)

### Fluid Routing

- Fixed `BasicFluidFilter` input initialization producing negative amounts that prevented all fluid transfer
- Fixed fluid routing to empty output tanks returning null filter

## Patchouli Documentation

- Added Blood Tank guide entry with crafting and upgrade recipes
- Updated routing node documentation to cover fluid and energy routing
- Renamed "Item Routing" category to "Routing Network"
- Updated upgrade descriptions to reflect multi-resource transfer rates

## Testing

- Added 75 game tests via NeoForge GameTest framework covering:
  - Routing nodes (items, fluids, energy, filters, priority, upgrades, topology)
  - Blood Altar (crafting, LP, tier detection, multiblock validation)
  - Hellfire Forge (crafting, will consumption, input validation)
  - ARC (smelting, tool/input validation)
  - Alchemy Table (slot validation, crafting with bound orb, LP syphon)
  - Demon Will (crystal growth, chunk aura, crucible)
  - Alchemy Array (recipe detection, crafting completion)
  - Imperfect Rituals (catalyst block matching)
  - Soul Network (LP add/syphon, altar orb filling)
  - Data validation (recipes, registries, datamaps)
  - Multiblock structures (altar tiers, ritual rune validation)
