# 1.1.21

## Changes

- Added item tags for Orbs of Vitae (all orbs, and one tag per tier), sigils, ritual tools, scribe tools, the Node Router, activation crystals, teleposer foci, dungeon keys and throwing daggers, so backpack and pipe filters can match them. The Node Router also counts as a wrench.
- Demonite Ore now carries the specific hellforged ore tag that other mods look for, alongside the general ore tag.

## Translations

- Updated Simplified Chinese translation, thanks to ChuijkYahus.
- Updated Brazilian Portuguese translation, thanks to PrincessStellar.
- Updated translations for Arabic, Czech, Danish, German, Greek, Spanish, Finnish, French, Italian, Japanese, Norwegian, Dutch, Polish, European Portuguese, Romanian, Russian, Swedish, and Ukrainian.
- Translations are now contributed through pull requests on GitHub. See the translations folder in the repository for how to add or update a language.
