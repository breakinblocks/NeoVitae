# 1.0.20

## Fixes

- Fixed a crash when crafting in the Tabula Vitae. Lengthening or strengthening a flask that already held an effect, and certain other table crafts, could cause a crash. The table now completes these crafts safely.
- The Sentient Extraction ritual no longer breaks Sentient Armour. It was also stripping the armour's internal experience-gaining cores, so afterwards the armour could no longer earn experience or reach the next level (it appeared stuck one point below every threshold) and it produced blank, unnamed tomes. Extraction now returns only your real upgrades, keeps the armour able to level, and frees its upgrade points correctly. Armour already stuck this way repairs itself the next time you equip it.
